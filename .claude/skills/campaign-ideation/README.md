# Campaign Ideation Engine — Moteur d'idéation de concepts publicitaires

Un système qui transforme **une vérité stratégique de marque (`A`)** en **plusieurs territoires
de concepts de campagne**, via 13 mécaniques créatives récurrentes regroupées en 6 familles.

> Philosophie : *1 vérité stratégique → 10, 20, 30 façons de construire un concept — sans
> produire 30 idées génériques.* La créativité vient de la **transformation** de `A`, pas d'un
> brainstorming aléatoire.

## Utilisation rapide

Donner au moteur :
```
Marque X
A = [valeur / bénéfice / mission / preuve / savoir-faire / comportement]
(+ cible, objectif, contexte, contraintes si possible)
```
Obtenir : une exploration structurée de plusieurs façons de penser la campagne, chaque territoire
ancré dans un pattern nommé, filtré par le test « Could be any brand ? ».

Dans Claude Code : la skill se déclenche sur les briefs créatifs (voir `SKILL.md`).

## Les 13 patterns, en un coup d'œil

- **ÉCHELLE** — Généralisation · Amplification
- **SOUSTRACTION** — Absence
- **RENVERSEMENT** — Inversion · Paradoxe
- **PROPAGATION** — Conséquence · Substitution / L'Ennemi
- **INCARNATION** — Matérialisation · Personnification · Métaphore · Preuve spectaculaire
- **DÉPLACEMENT** — Changement de perspective · Détournement / Révélation

## Note sur les exemples

Les campagnes citées sont réelles et documentées. Années et détails restent à vérifier avant
tout usage client. Aucune campagne, aucun claim, aucun résultat n'a été inventé.
